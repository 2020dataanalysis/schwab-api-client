# Schwab API Client

Production-ready Python Schwab API client library.

## Features

- OAuth2 Authorization Code Flow
- Refresh Token Flow
- Automatic Access Token Refresh
- Quotes
- Movers
- Market Hours
- Historical Price Data
- Option Chains
- Orders

## Architecture

schwab-api-client
    ↓
Stock Alert SaaS
    ↓
Analytics Engines
    ↓
Prediction Engines
